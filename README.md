# 🐱 貓咪巴士注音樂園 (CatBus Zhuyin Playground)

> **一起聽、一起玩，搭上可愛的貓咪巴士，出發去注音森林！**  
> 專為台灣幼兒園中大班、小一新生及華語學習者量身打造的**零壓力、高互動注音符號學習網頁遊戲**。

🎮 **線上立即玩 (GitHub Pages)**：[https://cconecone-cmyk.github.io/catbus-zhuyin/](https://cconecone-cmyk.github.io/catbus-zhuyin/)

---

## ✨ 遊戲四大核心單元

| 單元 | 圖示 | 核心特色與教學目的 |
| :--- | :---: | :--- |
| **👂 聽音找找** | 👂 | 隨機播放標準注音發音或生活例字，孩子點選對應的注音卡片。答對獲取閃亮小星星 ⭐，答錯溫柔鼓勵再試一次，建立聽辨音自信。 |
| **🌼 認識注音** | 🌼 | 完整涵蓋 **21 個聲符**、**3 個介符**、**13 個韻符**（共 37 個符號）。支援「注音＋例字引導」與「純注音單音」兩種發音模式。 |
| **🚌 拼音巴士** | 🚌 | 聲符與韻符/介符的二拼互動巴士！自由選擇符號搭上小巴，即時拼出「ㄅ＋ㄚ ➔ 巴」、「ㄇ＋ㄚ ➔ 媽」等常用字詞並朗讀。 |
| **🎨 寫寫畫畫** | 🎨 | **① 跟著描寫**：標準九宮格/米字格、箭頭筆向、起點圓點與逐筆動畫導引。<br>**② 空白板練習**：37 個注音任意切換，自由手寫練習、一鍵擦除與語音複習。 |

## 🔊 聲音與發音引擎特色 (四重無縫備援)

針對行動裝置（iOS Safari、Android Chrome）、弱網環境或離線情境，提供業界最高規格的四重發音保險：

1. **第一重：台灣標準國語幼教音檔 (`./audio/`)**
   - 採用親切溫柔的台灣幼兒園/小學標準國語發音（標準臺灣腔，非大陸捲舌音）。
   - 內建 37 個注音符號標準單讀音、37 條完整例字引導句、40 組二拼生活詞彙與 6 組激勵語音。
2. **第二重：GitHub Pages CDN 全球雲端鏡像**
   - 即使單獨下載 HTML 檔案到不同資料夾開啟，也能自動透過 CDN 載入發音音檔，隨點即聽。
3. **第三重：Web Audio API 零延遲合成音效**
   - 答對歡呼叮咚三連音、答錯啵啵彈簧音、按鈕水滴音、貓咪巴士嘟嘟喇叭聲，100% 瀏覽器原生運算，0 KB 下載、零延遲、免任何外部音檔。
4. **第四重：Web Speech API (`SpeechSynthesis`) 離線備援**
   - 遇極端離線斷網且無本地檔案時，自動切換至裝置內建之 `zh-TW` 語音引擎朗讀。

## 🚀 本地執行與離線使用

本專案採現代純原生前端架構（Pure HTML5 / CSS3 / ES6 / Web Audio / Canvas），**無需安裝 Node.js、無需任何 npm 建置步驟**：

1. 下載或複製本儲存庫：
   ```bash
   git clone https://github.com/cconecone-cmyk/catbus-zhuyin.git
   ```
2. 直接以瀏覽器雙擊打開 `index.html`，即可完整遊玩！

## 📂 專案檔案結構

```
catbus-zhuyin/
├── index.html               # 核心遊戲完整單頁（含四種遊玩模式、畫板與聲音引擎）
├── audio/                   # 完整音檔庫 (~2.0 MB)
│   ├── zhuyin/              # 37 個注音標準單讀音 (ㄅ.mp3 ~ ㄦ.mp3)
│   ├── examples/            # 37 條教學例字音 (ㄅ_玻.mp3 ~ ㄦ_兒.mp3)
│   ├── words/               # 40 組拼音詞彙語音 (ㄅㄚ.mp3、ㄇㄚ.mp3...)
│   ├── feedback/            # 遊戲過關、鼓勵與提示語音 (correct.mp3 等)
│   ├── sfx/                 # 遊戲原生音效 (correct, click, bus, star...)
│   └── github_raw/          # 開源社群注音數據庫備援
└── README.md                # 專案說明文件
```
